# PHYSICA V4 — Guided Curriculum

25 guided chapter introductions, worked examples and quizzes, local lesson progress, and three existing interactive labs. Lessons outside chapters 3, 9 and 16 are **introductory coverage**, not full textbook units.

## Windows PowerShell

```powershell
cd F:\physica-v4
npm install
npm run test
npm run build
npm run dev -- --host 127.0.0.1 --port 5176
```

Do not overwrite V3 before verifying V4.

## Git

```powershell
git init
git add .
git commit -m "feat: 25 chapter guided curriculum and three labs"
```

To publish, create an **empty** GitHub repository first, then follow GitHub’s printed remote commands. Never commit tokens or `.env` files.
